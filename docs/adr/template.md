# NNNN. Title in the imperative

- **Status:** Proposed
- **Date:** YYYY-MM-DD
- **Approver:** name (@handle), or "pending"
- **Implemented by:** issue links

## Context

The forces at play. What is true today, what breaks, and why a decision is
needed now. Cite files and issues rather than describing them abstractly.

## Decision

The seam, stated so that someone can tell whether a pull request conforms.
Include what is explicitly out of the decision's scope.

## Consequences

What becomes easier, what becomes harder, what must now be true everywhere,
and what has to change to comply.

## Alternatives considered

Each rejected option and the reason it was rejected. An alternative with no
stated reason is not an alternative.

## Links

Related records, issues, and code.
