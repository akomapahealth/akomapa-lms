# Triage labels

The engineering skills use the following canonical workflow labels.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Work is waiting on additional information. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and can be implemented without additional human decisions. |
| `ready-for-human` | `ready-for-human` | The issue requires a human decision, approval, or implementation step. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

Priority, type, and area labels supplement these workflow labels but do not replace them.
